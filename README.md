# Proyecto de Prueba de JavaScript

Este proyecto fue creado como un **ejercicio personal para practicar JavaScript** mientras aprendía los conceptos básicos del lenguaje.

## Descripción

El objetivo de este proyecto es experimentar con **JavaScript puro**, manipulando el DOM, eventos y lógica básica para entender cómo funciona el lenguaje y cómo interactúa con HTML y CSS.

### Funcionalidades

- Ejercicios de manipulación del DOM
- Manejo de eventos (`click`, `input`, etc.)
- Funciones y variables en JS
- Condicionales y bucles
- Validaciones simples

## Tecnologías utilizadas

- JavaScript (ES6+)
- HTML5
- CSS3
